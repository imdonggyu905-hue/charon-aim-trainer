# Charon Aim Trainer

브라우저에서 실행하는 독립형 FPS 에임 연습 도구입니다. Kovaak's 스타일의 연습 흐름에서 아이디어를 얻었으며, Kovaak's 또는 Ch1ron의 공식 제품·공식 루틴은 아닙니다.

## 실행
GitHub Pages 배포 후 아래 주소에서 바로 실행할 수 있습니다.

https://imdonggyu905-hue.github.io/charon-aim-trainer/

## 모드
- **Micro Flick**: 작은 표적을 빠르게 클릭
- **Sphere Track**: 움직이는 표적을 조준점으로 따라가기
- **Precision Click**: 크기가 다른 표적을 정확하게 클릭
- **Reactive Switch**: 표적이 바뀔 때마다 빠르게 전환

## 설정
기본 감도 표시는 DPI 800, 게임 내 감도 0.37입니다. 실제 게임의 감도를 자동으로 가져오지는 않으며, 브라우저의 마우스 입력은 게임과 완전히 같지 않을 수 있습니다.

## 배포
GitHub 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택하면 정적 사이트로 배포할 수 있습니다.
